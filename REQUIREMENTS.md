# 📦 Requirements

The following dependencies are required to run the Caesar CLI tool:

| Package        | Version | Description                                                                  |
| :------------- | :-----: | :--------------------------------------------------------------------------- |
| **`colorama`** | Latest  | Provides cross-platform colored terminal text to enhance the CLI experience. |

## 🛠️ Installation

You can install the required dependencies using `pip`:

```bash
pip install -r requirements.txt
```

> **Note**: While this file is documented as `.md` for readability, it is recommended to keep a `requirements.txt` for compatibility with `pip`.
