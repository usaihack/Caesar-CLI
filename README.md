## 🧐 About

**Caesar CLI** brings the historical encryption technique to your modern terminal. Whether you're a cryptography enthusiast, a developer, or just someone who loves secret messages, this tool offers a seamless and **visually appealing** way to encrypt and decrypt text.

Built with **Python** and enhanced with **Colorama**, it provides a clean, interactive interface that handles all standard characters including uppercase, lowercase, numbers, and symbols.

---

## ✨ Key Features

| Feature                        | Description                                                           |
| :----------------------------- | :-------------------------------------------------------------------- |
| **🔐 Encryption & Decryption** | Seamlessly switch between modes to secure or reveal your messages.    |
| **🔠 Full ASCII Support**      | Handles `A-Z`, `a-z`, `0-9`, and special symbols with ease.           |
| **🎨 Beautiful UI**            | Enhanced with `Colorama` for a vibrant and clean terminal experience. |
| **⚡ Instant Feedback**        | Real-time processing for quick results.                               |
| **🛠️ Cross-Platform**          | Works flawlessly on **Windows**, **macOS**, and **Linux**.            |

## 🚀 Installation

Getting started is easy! Choose your preferred method below.

### 🐧 Linux / macOS

```bash
# Clone the repository
git clone https://github.com/usaihack/Caesar-CLI.git
cd Caesar-CLI

# Create a virtual environment (Optional but Recommended)
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the tool
python3 caesar.py
```

### 🪟 Windows

```powershell
# Clone the repository
git clone https://github.com/usaihack/Caesar-CLI.git
cd Caesar-CLI

# Install dependencies
pip install -r requirements.txt

# Run the tool
python caesar.py
```

## 💻 Usage

Once installed, simply run the script to enter the interactive menu:

```bash
python caesar.py
```

### 📸 Example Session

```text
[?] Choose an option:
    1. Encrypt
    2. Decrypt
> 1

[?] Enter text to encrypt: Hello World!
[?] Enter shift amount: 3

[+] Encrypted Text: Khoor Zruog!
```
